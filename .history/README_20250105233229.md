# 一、问题描述
社交网络分析（Social Network Analysis，SNA）是一门研究社会结构中个体（节点）之间关系（边）及其互动模式的学科。随着在线社交服务的快速发展，社交网络已深入社会经济生活的各个方面，成为无处不在的计算平台和信息传播平台。
在社交网络中，信息传播的速度和范围远超传统媒介。理解信息在网络中的传播机制，对于预测信息扩散路径、识别关键传播节点、控制虚假信息传播等具有重要意义。然而，社交网络的复杂性和动态性使得信息传播规律的研究充满挑战。


本项目旨在开发一个可视化工具，帮助用户上传和管理社交网络数据，模拟信息在网络中的传播过程，并提供直观的图形展示。该工具可以实现以下功能：
- （1）将用户上传的特定格式CSV文件转换为符合要求的JSON格式；
- （2）数据格式校验、错误提示、数据下载等功能；
- （3）基于经典的信息传播模型IC，模拟信息在网络中的扩散过程，帮助理解传播机制；
- （4）以图的形式展示网络结构和信息传播路径，直观呈现节点之间的关系和互动。
基于以上功能，本项目实现了一个便捷的工具，辅助分析社交网络中的信息传播规律，识别关键节点，制定有效的传播策略，或控制不良信息的扩散。这对于深入理解社交网络的运行机制，提升信息传播的有效性和安全性，具有重要的实践意义。

# 二、项目技术概览
1. 本项目采用 HTML、CSS和 JavaScript 作为开发语言，具体如下：
- （1）HTML：用于定义页面结构，支持动态加载功能界面;
- （2）CSS：用于页面布局和样式设计，确保界面美观协调;
- （3）JavaScript：核心逻辑实现语言，用于处理图数据、执行算法（如介数中心性计算）、模拟信息扩散等。

2. Cytoscape.js 简介及其在本项目中的应用
Cytoscape.js 是一个js编写的图论可视化库，提供了丰富的功能，能够实现在网页中帮助数据科学等相关领域的研究者显示操作丰富的交互式图形。它支持复杂的布局算法、样式定义和动态交互。  
在本项目中，Cytoscape.js 的应用包括：
- （1）图的可视化：展示社交网络中的节点（用户）和边（关系）；
- （2）布局算法：通过层次布局（breadthfirst）直观展示网络结构；
- （3）动态样式更新：根据用户操作（如信息扩散或关键人物分析）实时改变节点颜色或边权值；
- （4）交互功能：支持用户动态操作图形（如缩放、拖拽）。

# 三、模块介绍
本项目包含以下主要功能模块：
### 1. 功能介绍模块
在主页中显示各功能的简要介绍，包括信息传播模拟、关键人物（度中心性、介数中心性、割点）可视化、界面可视化选项和数据管理。用户可以通过该模块快速了解系统提供的功能及其用途。
### 2. 模拟传播模块
该模块基于IC模型实现信息扩散模拟，
- 起点选择：用户定义传播起点和传播步数；
- 动态更新：实时展示扩散过程中每一步的传播节点，起点、最新传播节点和已传播节点以不同颜色区分。
其运用到的关键算法是广度优先搜索。

### 3. 关键人物可视化模块
该模块支持三种图算法，可以帮助用户识别社交网络中的关键节点，包括以下三种：
- 度中心性：与其他节点连接最多的节点；
- 介数中心性：基于`floyd`算法计算节点的桥梁作用；
- 割点：删除后会导致网络分裂的节点，基于`tarjan`算法。
这些结果可以通过颜色和标签的动态更新直观地展示出来。

### 4. 可视化选项板块
用户可通过该板块自定义图的样式，包括是否显示节点序号以及自定义节点颜色（支持多种颜色选项）。

### 5. 数据管理模块
数据管理包括数据上传、数据校验、数据转换和数据应用，各具体功能如下：
- 数据上传：用户上传符合要求的 CSV 文件；
- 数据校验：检查上传的文件格式是否正确；
- 数据转换：将 CSV 文件转换为 JSON 格式，并下载；
- 数据应用：将用户上传的数据应用到图中。
